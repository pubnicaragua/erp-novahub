Ubicación y privacidad

La ubicación del teléfono puede estar activa, pero el navegador tiene bloqueado el permiso para este sitio.

  1. Abre el candado o el icono de ajustes junto a la dirección.
  2. En Ubicación selecciona Permitir.
  3. Recarga NovaHub y vuelve a intentarlo.
Compartir mi ubicación con el equipoEsta opción solo controla tu última ubicación visible para vendedores autorizados. No cambia el permiso del teléfono.
Proveedor y fuente del mapaSuper Admin o administrador puede elegir Google Maps, OpenStreetMap o una fuente propia. Las URLs deben ser HTTPS y las claves permanecen fuera de la base de datos.
